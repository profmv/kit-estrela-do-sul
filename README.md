# Kit Estrela do Sul — Power BI

Portal público da atividade prática de Power BI sobre bilhetagem rodoviária da
empresa fictícia **Estrela do Sul**.

## Acesse

- Site da atividade: <https://profmv.github.io/kit-estrela-do-sul/>
- Empresa fictícia: <https://sitefic-estreladosul.onrender.com/>

## O desafio

O aluno recebe dados prontos e entrega um dashboard com quatro páginas:

1. visão executiva;
2. demanda e trechos;
3. clientes e vendas;
4. frota e operação.

O portal oferece uma base iniciante com uma tabela, uma base recomendada com seis
tabelas, guia de apoio, tema visual, modelo de relacionamentos, exemplos DAX,
checklist e glossário contextual.

## Dados

Todos os registros são sintéticos. Nomes e CPFs fictícios foram preservados para
as atividades de qualidade, relacionamento e privacidade. RGs, contatos e placas
dos pacotes públicos usam marcadores `SINT` inequívocos.

As bases-resposta e os materiais exclusivos do professor não fazem parte desta
publicação.

## Publicação

Site estático em HTML, CSS e JavaScript, publicado pelo GitHub Pages a partir da
raiz da branch `main`. Não há build nem dependências de execução.
